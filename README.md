# Medicine Inventory System 💊

The Medicine Inventory System is a mobile application developed to efficiently manage and monitor medicine inventory. It helps in organizing medicine data and maintaining proper stock records. The system supports full CRUD operations for handling medicine information.

The application is integrated with Firebase for real-time database functionality and seamless data synchronization. It is designed with a simple and intuitive user interface to ensure easy navigation and effective inventory management.

## 🚀 Features
- Add new medicine records  
- View available medicine list  
- Update medicine details  
- Delete medicine records  
- Real-time database integration using Firebase  
- Clean and easy-to-use UI  

## 🛠️ Tools Used
Java, XML, Firebase, Android Studio
